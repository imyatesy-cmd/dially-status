# Dially build status

A running view of how far along Dially is: a new dialler (call-centre phone system) being built step by step.

This repository is generated automatically. It holds only the static page (`index.html`, `assets/`) and one data file (`data.json`) containing progress percentages, counts and plain-English summaries. It contains no code, no customer data and no technical details of the systems behind the project.

Please do not open pull requests here: every commit is overwritten by the next automatic update.
